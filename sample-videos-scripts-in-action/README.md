# Sample videos — the scripts in action

A selection of short screen recordings showing what the scripts in this repository do inside MoI.
One video per script, added as each one gets a recording worth watching.

Each clip plays in the page below. Use the player's own menu to download one if you want to keep
it.

## MultiPipe

A network of curves becomes one solid pipe frame in a single step: picking the curves, setting the
options, the build, and the summary before anything is added to the document.

The command is in [`scripts/multipipe/`](../scripts/multipipe/), and its
[manual](../scripts/multipipe/MultiPipe-manual.html) covers every option and message.
